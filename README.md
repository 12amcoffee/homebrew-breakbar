# homebrew-breakbar

Homebrew tap for [BreakBar](https://github.com/12amcoffee/BreakBar), a macOS menu bar Pomodoro
timer with a Rest window.

## Install

```bash
brew tap 12amcoffee/breakbar
brew install --cask breakbar
```

Recent versions of Homebrew refuse to load casks from third-party taps until you trust them. If you
see `Refusing to load cask … from untrusted tap`, run this once and then install again:

```bash
brew trust 12amcoffee/breakbar
brew install --cask breakbar
```

## Update

```bash
brew update
brew upgrade --cask breakbar
```

## Uninstall

```bash
brew uninstall --cask breakbar
```

Add `--zap` to also remove BreakBar's settings and its event log.

## Notes

- BreakBar is **not notarised by Apple**. This cask removes macOS's download quarantine flag after
  installing, so the app opens without the "Apple could not verify" warning. If you would rather
  keep that safety check, install the app from the
  [Releases page](https://github.com/12amcoffee/BreakBar/releases/latest) instead.
- Requires macOS 13 (Ventura) or later. Works on Apple silicon and Intel.
- The cask file `Casks/breakbar.rb` is generated by BreakBar's release workflow and copied here.
